# Day 6 – Linux Fundamentals

## Core Commands
pwd – show current directory
ls / ls -la – list files
cd – change directory
mkdir – create directory
touch – create file
rm / rm -r – delete

## Important Directories
/ – root
/home – user files
/etc – configs
/var/log – logs
/tmp – temp

## Permissions
r = 4
w = 2
x = 1
chmod 644 file.txt
chmod 755 script.sh

## Admin
sudo command
